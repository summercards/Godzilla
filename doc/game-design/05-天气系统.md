## 1. 现状与目标

线上已经有两样东西：`rain`（常驻雨）和 `lightning` / `bolt`（随机闪电）。
它们是**纯视觉**的 —— 除了给画面加一层雨丝和偶尔闪一下，不参与任何结算。

**目标是让天气成为环境层：它改变打法与经济结构，但不改变"能不能打下去"。**

三条设计约束：

1. **天气永远不是纯惩罚。** 每个天气都必须给玩家一条好处（见支柱 3）。
   一个只让人变慢的天气 = 一个让人关掉游戏的天气。
2. **不落盘。** 天气完全由 `seed + district` 确定性派生，**不新增任何存档字段**。
   这既守住了铁律 5（随机必须确定性），也把改动风险降到最低 ——
   天气系统**一行都不碰存档格式**。
3. **第 1 章不接入。** 区域 1–5 保持现有的常驻雨与闪电，观感一个字不变。

## 2. 天气模型

```
天气 = 主天气（每关固定，可有 25% 概率换为异常主天气）
     + 叠加现象（30% 概率，最多 1 个）
     + 强制天气（仅在特定 Boss 阶段，覆盖前两者）
```

| 类别 | 数量 | 说明 |
| --- | ---: | --- |
| 主天气 | 6 | 决定天空、整体色调与核心修正 |
| 叠加现象 | 5 | 在主天气之上加一层局部效果 |
| 强制天气 | 1 | 静默，只由 Boss 切换 |

**强度分级**：1 / 2 / 3，抽取权重 `[50%, 35%, 15%]`。强度线性放大该天气的所有修正项。

```
实际修正 = 基础修正 × 强度
```

### 生效时机（对齐关卡的 4 段结构）

| 关卡段 | 天气 |
| --- | --- |
| ① 接敌段 0–20% | **不生效**（给玩家看清本关敌人的窗口） |
| ② 街区段 20–55% | 满强度生效 |
| ③ 封锁段 55–80% | 满强度生效 |
| ④ 要塞段 80–100% | 满强度生效；Boss 阶段转换时可能强制切换 |

### 随机规则

```js
// 确定性派生，不使用 Math.random()
function weatherFor(district, seed) {
  const rng = mulberry32(hash(seed, district));   // 见 06 §6
  const main = pick(DISTRICT_WEATHER[district], rng);          // 主天气
  const overlay = rng() < 0.30 ? pick(OVERLAYS, rng) : null;   // 叠加现象
  const intensity = weighted([1, 2, 3], [0.50, 0.35, 0.15], rng);
  return { main, overlay, intensity };
}
```

**同一区域每次进入的天气完全一致** —— 不需要存档，也不会因为读档而变天。

## 3. 主天气

### W-1 晴

| 项 | 内容 |
| --- | --- |
| 视觉 | 现有的新宿夜景，无雨、无云，月光清亮。**唯一一个能看清全城轮廓的天气** |
| 玩家 | 无修正（纯基线） |
| 敌人 | 无修正 |
| 经济 | **核能产出 +15%**（无云层遮蔽，辐射散热最好） |
| 一句话 | 什么都不发生，正好看看它现在长什么样。 |

### W-2 潮雨（区域 6 主天气）

| 项 | 内容 |
| --- | --- |
| 视觉 | 沿用现有雨幕 + 地面积水反光；强度 3 时地面出现浪涌线 |
| 玩家 | 吐息伤害 **+10%**（水汽助导电）；行进 **-5%**（泥泞） |
| 敌人 | 水面单位耐久 **+10%**（浪涌掩护）；空中单位精度 **-15%** |
| 经济 | 建筑倒塌激起蒸汽，破坏收益 **+10%** |

### W-8 台风（区域 9 主天气）

## 6. 天气 × 成长：加权突变池

这是天气系统真正的深度所在 —— **天气不只是这一关的修正，它决定这一关里你会长成什么。**

升级触发随机突变时（见 [`06-成长系统.md`](06-成长系统.md) §4），
当前天气会给突变池加权：

```js
weight(mutation) = baseWeight(mutation) × weatherBias(mutation.tags, weather)
```

举例：

| 天气 | 加权效果 | 体感 |
| --- | --- | --- |
| 磁暴 / 雷击 | 雷系突变 ×2.2，且稀有度上浮 10% | 在雷暴里升级更容易长出「雷脊」 |
| 火山灰 / 地热蒸汽 | 熔系突变 ×2.0 | 地热区更容易长出熔岩裂纹 |
| 血月 | 稀有度上浮 30% | 首都那一关的成长特别值钱 |
| 静默 | 稀有度上浮 50% | 最难熬的阶段给最好的回报 |

**这就是"想看看下一级长什么样"的机制来源** —— 玩家会开始留意
"现在是什么天"，因为天气决定他这头巨兽往哪个方向长。

## 7. 关卡绑定

| 关 | 区域 | 主天气 | 叠加现象 | 异常替换概率 |
| ---: | ---: | --- | --- | ---: |
| —— | 1–5 | **不接入**（保持线上常驻雨 + 闪电） | — | — |
| 6 | 6 | 潮雨 | 海雾 | 25% |
| 7 | 7 | 火山灰 | 酸雨 / 地热蒸汽 | 25% |
| 8 | 8 | 磁暴 | 雷击 | 25% |
| 9 | 9 | 台风 | 雷击 | 25% |
| 10 | 10 | 血月 | 无（静默由 Boss 强制） | 0% |

「异常替换」= 25% 概率把主天气换成同章另一个更极端的主天气（强度必定 3，
修正 ×1.5），换取该天气的突变权重加成再 +20%。这是给重复循环时的一点变化。

## 8. 实现映射

| 文件 | 改动 |
| --- | --- |
| `tv/game.js` | 新增 `weatherFor(district, seed)`、`updateWeather(dt)`；把 `rain` / `lightning` 的硬编码改为读天气强度；在 `pressure()` / `doBeam()` / `grant()` / 建筑结算处插入天气修正项 |
| `tv/progression.js` | 突变抽取时读取当前天气做加权（天气对象由 `game.js` 传入，**不落盘**） |
| `tv/index.html` / `tv/style.css` | 天气 HUD（区域名旁显示天气图标 + 强度），Boss 阶段切换时横幅报一次 |
| 存档 | **不改** —— 天气完全由 `seed + district` 派生 |

新增的确定性随机函数（`mulberry32` / `hash`）应放在 `progression.js` 中，
与突变系统共用同一份实现。
