## 二、时基与主循环

`game.js` 的 `frame()` 是唯一的时间入口，两种时钟**必须分开**：

```js
function frame(now){
  let rawDt = (now-last)/1000; last = now;
  let wallDt = rawDt;                       // 收入时钟
  if(rawDt > 3){                            // 长停顿 → 走离线结算
    const seen = economy.data.lastSeen;
    catchUp(Date.now());                    // 离线入账（含 XP 折算）
    wallDt = Math.max(0, rawDt - (economy.data.lastSeen-seen)/1000);  // 扣掉已认领时段
    rawDt = 1/60;
  }
  let dt = Math.min(rawDt, .05) * (slow>0 ? .36 : 1);   // 物理步长 + 慢动作
  update(dt, wallDt); render(); requestAnimationFrame(frame);
}
```

| 时钟 | 钳制 | 谁用 | 为什么 |
| --- | --- | --- | --- |
| `wallDt` | **不钳** | `economy.tick(wallDt)`、UI 计时、`particles.life` 之外的存档计时 | 收入必须覆盖真实流逝的**全部**时间。旧实现钳到 0.15s 而离线只在 rawDt>3 触发，`(0.15, 3]` 这一段两处都不认账，时间直接蒸发 |
| `dt` | `min(x, .05)` | 战斗、物理、动画、行走 | 只对物理步长有意义；钳制避免掉帧后跳帧 |

- `panelMode` 时不跑帧（面板只渲染一次静态全息图）。
- `slow` 由爆炸/爪击/重踏设置，卡到 0.36 倍速。
- 面板窗口**不写盘**：`save()` 第一句 `if(panelMode)return;`。

### 渲染管线

| 项 | 值 |
| --- | --- |
| 离屏画布 | `640×360`（`buffer`），`imageSmoothingEnabled=false` |
| 输出 | `out`（1280×720），`ctx.setTransform(.5,0,0,.5,0,0)` → 逻辑坐标即 640×360 |
| 世界→屏幕 | `s = sceneZoom × zoom × 0.8`；`y ↦ (y−G)×s + H×0.72`；**地面线 = 518.4px** |
| `sceneZoom` | = `growth.cameraScale()`，平滑逼近 |
| `zoom` | 动作推镜：吐息 1.045 / 咆哮 1.025 / 其余 1 |
| `camera` | 平滑逼近 `cameraTarget() = p.x − (420 + 140×clamp((bodyScale−.333)/.787, 0, 1))` |

绘制顺序：天空 → 地面 → 后排楼 → 主街楼 → 残骸 → 存活敌 → 巨兽 → 光束 →
炮弹 → 濒死敌 → 火 → 粒子 → 前景楼 → 屋顶遮挡 → 天气 → 暗角 → 推图轨道。

## 三、世界与推图

### 3.1 尺寸常量

| 常量 | 值 | 含义 |
| --- | ---: | --- |
| `W/H` | 1280 / 720 | 逻辑画幅（实际按 640×360 画） |
| `G` | 590 | 地面线世界 y |
| `LENGTH` | 4800 | 一张地图的基准长度（首块） |
| `CHUNK_SPAN` | 3400 | 越界后每块追加的长度 |

### 3.2 建筑

一张地图 **51 栋**，三层（`generateWorld`）：

| layer | 名称 | 起点 x | 步长 | 数量 | 基础耐久 | 高度基准 | 地面偏移 |
| ---: | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 后排 | 560 | 185 | 21 | 520 | 210 | −14 |
| 1 | 主街 | 650 | 210 | 18 | 780 | 210 | 0 |
| 2 | 前景 | 810 | 310 | 12 | 360 | 90 | +32 |

耐久（`game.js` 的 `b.max=b.hp=…`）：

```
hp = round( 3 × base(layer) × Kb(district) × (1 + max(0, h − 基准高)/500) )
Kb(d) = 1 + (d−1) × growth.DISTRICT.coef        // coef = 0.22
```

- **主街与后排用同一个 `Kb`，前景也是** —— 与巨兽伤害共用 `DISTRICT.coef`，由
  `tests/growth-system.test.cjs` 钉着不许分叉。
- 高楼（`h` 大）额外加耐久，区域推进整体变硬。
- 存档保存 `hp/max/dead`，读档**按损伤比例**恢复（`hp = 新max × 旧hp/旧max`），
  已倒的保持倒。旧档没有 `max` 时按 `(230/120/85)×(1+(d−1)×0.12)` 反推。

### 3.3 敌人

**固定部署 16 个**（`x = 620 + i×253`）+ **1 个城门**（`x = LENGTH−390`，`hp×2`，
`gate=true`，`district≥2` 且非村庄阶段）。村庄阶段额外插无人机。

单位表（`TYPES`，`hp` 与 `resistance` 是仅有的玩法数值，显示名与目录从
`asset-index.js` 取）：

| type | 显示名 | 基础耐久 | 压制权重 | 击破收益 |
| --- | --- | ---: | ---: | ---: |
| tank | 主战坦克 | 90 | 0.07 | 20 |
| heli | 武装直升机 | 80 | 0.06 | 24 |
| rocket | 火箭炮车 | 160 | 0.13 | 35 |
| gunship | 重装武装直升机 | 230 | 0.19 | 48 |
| aegis | 电磁装甲车 | 360 | 0.31 | 65 |
| mech | 重型攻城机甲 | 600 | 0.45 | 100 |
| jet | 喷气战机 | 70 | 0.05 | 18 |
| drone | 侦察无人机 | 38 | 0.03 | 11 |
| walker | 四足攻城兽 | 340 | 0.28 | 55 |
| bunker | 要塞炮台 | 430 | 0.34 | 62 |

生成耐久：

```
hp = base(type) × Ke(district) × (当前阶段 === 'village' ? 0.6 : 1)
Ke(d) = 1 + (d−1) × 0.19          // 低于建筑的 0.22，刻意留的差
```

动态增援：`spawnTimer` 每 12 秒检查一次，**近处（±1100px）存活敌 < 6** 且
`p.x < LENGTH−800` 时补 1 个，兵种池按区域分档：

| 区域 | 增援池 |
| --- | --- |
| 村庄阶段 | tank, heli, drone |
| d = 1 | tank, heli, drone |
| d ≥ 2 | rocket, heli, drone, jet |
| d ≥ 3 | gunship, rocket, jet, drone, walker |
| d ≥ 5 | gunship, aegis, mech, jet, drone, walker, bunker |

**远距离敌人休眠**：`|e.x − p.x| > 1350` 时跳过更新（不射击、不移动），
且玩家前进时非飞行单位**不追**；飞行单位在 >600px 时以 27px/s 缓慢接近。

### 3.4 无限延伸（区块流式）

地图不是有限的 —— 走到 `LENGTH−1900+(chunk−1)×3400` 就 `appendWorldChunk()`
再铺 3400px、3 层楼 + 10 个固定敌，`worldChunk++`。同时回收 `p.x−2200` 之后的
建筑与敌人，所以长时间挂机不会无限涨内存。

区块播种是**独立的**：`seed = 1701 + district×983 + worldChunk×7919`，所以只重建
存档附近的两块也能还原同一栋楼的长宽高（`generateWorld` 只回放 `count−2 … count−1`）。

### 3.5 推图闸门

```
mapProgress() = mapGate ? 1
              : min(1, max(0, cleared − mapStartCleared)/12) × 0.6
              + min(1, max(0, kills   − mapStartKills  )/8 ) × 0.4
```

- `mapStart*` 随 `world` 落盘，推进时归位到当前值，下一区从 0 重算。
- **满 1 开闸并锁存**（`mapGate = { district: d+1 }`），不会因后续回落重关。
- 开闸只声明状态（`announceMapGate()` 仅 `hud()`），按钮文案与颜色全部由 `hud()`
  从 `mapGate` 派生 —— 单源在 `nextMapLabel()`。

推进结算 `requestNextMap()`：

```
district += 1;  dna += 2;
grant(180 + district×30, xpPerDistrict(district));   // 核能会再乘 rewardMult
mapStartCleared = cleared;  mapStartKills = kills;
generateWorld();  save();
```

按钮只在**观测面板**里出现，电视窗口自己从不显示它。

### 3.6 章节与阶段（两套彼此独立的阶梯）

| 概念 | 真源 | 驱动什么 | 是否落盘 |
| --- | --- | --- | --- |
| **章节** | `progression.js` `chapterFor(d)` | 天空/天气/街道名/建筑配色/地标 | **否**，由 `district` 派生 |
| **阶段** | `progression.js` `STAGES` + `stageIndexFor` | 楼高、兵种 tier、街道绘制方式 | 是（`world.stage`） |
| **形态期** | `EPOCHS` + `epochIndexFor(level)` | 体型区间、皮肤 | 否，由 `level` 派生 |

章节映射：`d 1–5 大阪` / `d 6–10 东京` / `d ≥ 11 纽约`。**跨章只有 5→6、10→11 两次**。

阶段门槛（`minMeters` 与 `minLevel` **同时**满足才升级）：

| 阶段 | 累计行程 | 等级 |
| --- | ---: | ---: |
| 现代村庄 | 0 | 1 |
| 城郊防线 | 2600 | 8 |
| 城区核心 | 7200 | 18 |

`meters += Δx × 0.12` —— 行程是**像素的 12%**，只喂阶段，**不驱动推图**。

三城视觉/天气（`CHAPTERS[].weather`，纯视觉，由 `currentChapter()` 取）：

| 章 | 天空时段 | 天气 key | 画面 | 闪电 |
| --- | --- | --- | --- | --- |
| 大阪 | dusk 黄昏 | `clear` | **无天气层**（晴空） | 否 |
| 东京 | night 午夜 | `thunder` | 压顶乌云（**不下雨**） | **是**，7–13 秒一次 |
| 纽约 | dawn 清晨 | `fog` | 云带 / 浓雾 | 否 |

三章天气互不相同，且**大阪与东京都不出现降水**（2026-09-20 主人反馈
「三个城市的天气也要分别一下，大阪和东京不用下雨」）。`density` 只对降水系
（`rain` / `storm`）有意义，非降水天气一律写 0。

## 四、自动战斗

### 4.1 决策优先级

每帧、且只在 `action === 'walk'` 时按顺序短路判断（`updateAI`）：

| 序 | 动作 | 触发条件（精确） |
| ---: | --- | --- |
| 1 | 重踏 stomp | `cd ≤ 0` 且（340px 内有**非飞行**敌 或 有建筑 `|b.x−p.x| < 210`） |
| 2 | 尾扫 tail | `cd ≤ 0` 且 有建筑 `|b.x−p.x+100| < 360` |
| 3 | 咆哮 roar | `cd ≤ 0` 且 340px 内敌 **≥ 2** |
| 4 | 爪击 claw | `meleeTarget`：主街阻挡楼在 `65+170×BS` 内 **或** 敌在 `(−35, 170)` 且非飞行 |
| 5 | 吐息 beam | `cd ≤ 0` 且有目标（见下） |
| 6 | 前进 walk | 以上都不成立 |

**吐息目标** `targetForBeam()`：前方 `+180 … +900` 内的存活敌，按
`(gate?1000:0) + hp` 降序；**每第偶数次动作**优先打最硬的敌，否则取前方
`+145 … +950` 内最左的非前景建筑，都没有再退回敌。

**近战优先于吐息**是硬序：近处有楼就先爪击，吐息即使冷却好了也等。

### 4.2 动作时序（伤害绑定时点，不是只播特效）

| 动作 | 时长 | 命中时点 | 冷却 | 落地函数 |
| --- | ---: | ---: | ---: | --- |
| walk | ∞ | — | — | — |
| claw | 1.18s | 0.54s | 0 | `doClaw()` |
| stomp | 1.68s | 1.00s | 12s | `doStomp()` |
| tail | 1.65s | 0.83s | 15s | `doTail()` |
| roar | 2.10s | 0.45s | 25s | `doRoar()` |
| beam | 4.20s | 0.95–3.55s 持续 | 28s | `updateBeam()` 每帧 |

冷却**从施放那一刻**起算（`begin()` 里赋值），`原始觉醒 overdrive` × 0.75
（吐息 28→21s）。每区首次吐息 **18 秒**（`generateWorld` 把 `cooldowns.beam` 设 18）。

### 4.3 伤害

统一入口：`power()` / `atomic()`（`progression.js`），**两者都不含等级膨胀**
（`COMBAT.levelScaling = false`）：

```
districtScale(d) = 1 + (d−1) × 0.22
power()  = (54 + 22×力量等级) × levelMult × districtScale × (1 + dmgBoost)
atomic() = (85 + 30×炉心等级) × levelMult × districtScale × (1 + beamBoost)
levelMult = 1（关掉 levelScaling 时的恒等，老行为是 1+(L−1)×0.07）
```

各动作的实际伤害：

| 动作 | 对建筑 | 对敌 | 范围 |
| --- | --- | --- | --- |
| claw | `power × 1`（前景楼 ×1.3） | `power × 1.4` | 爪端前方 70px / 敌 ±135px |
| claw + 震荡爪击 | 追加前方 70–260px `power × 0.4` | — | 溅射 |
| stomp | `power × (地脉崩解 ? 3.4 : 1.7)` | `power × 2.8`（不吃飞行） | `(360 或 576) × (1+spineBonus)` |
| tail | `power × 1.8` | `power × 2.2` | 建筑 `|b.x−p.x+100|<470`，敌 520px |
| roar | — | `power × 0.9` 且 `e.cd += 4`；**清空全部炮弹** | 850px |
| beam（光束） | 每秒 `atomic` | 同 | 射线 1100px |
| beam（火焰，有 pyro 副元素） | `atomic×1.25 + power×0.4` /秒 | 同 | 同 |
| beam × 红莲临界 | **×2.5**（每第 3 次吐息） | 同 | 同 |
| beam 等级微增 | `× (1 + (炉心等级−1) × 0.015)` | 同 | — |
| 残骸 crash | `power × (投掷 ? 1.3 : 0.35)`，150px | `power × (投掷 ? 2 : 0.45)`，100/200px | 落地二次爆炸 |

- **贯穿吐息 pierce**：`hits.slice(0, 3)`，第 2、3 个目标 ×0.65。
- **电离连锁 chain**：命中后对 280px 内最多 2 个敌各 `damage × 0.4`，并画电弧。
- 射线判定 `rayBox()` 对建筑用 AABB 求交，对敌用轴向偏移阈值
  （机甲 90px / 飞行 34px / 其余 42px）。

### 4.4 行进与压制

```
基础步速 = (30 + √动能等级 × 8) × (1 + speedBoost)      // 1 级 = 38
pressure = Σ 存活且 x ∈ (p.x−180, p.x+700) 的 resistance × (1 + district×0.05)
           不可阻挡 momentum ? ×0.6 : ×1
           ÷ (1 + (动能等级−1) × 0.09)
实际步速 = 基础步速 / min(3.4, 1 + pressure)
```

阻挡（`next` 取 min，三条同时生效）：

1. 主街楼：停在 `blocking.x − (50 + 170×BS)` —— **取决于当前体型**，小体型不会隔空挥爪；
2. 城门敌：停在 `gate.x − 160`；
3. 无论怎么走都要 `delta ≥ 0`，巨兽**只会前进不会后退**。

### 4.5 巨兽受击（无血条，纯反馈）

`updateEnemies` 里存活敌按各自 cd 射击（火箭车 4s / 电磁车 2.2s / 其余 3s，
机甲与重装直升机一次打两发）。炮弹瞄准点与命中判定**共用 `rig.hitbox(BS,…)`**：

```js
hb = KaijuRig.hitbox(BS, p.x, G)          // = BIND_BOUNDS × BS，锚点脚底
tx = p.x + rand(-0.05, 0.42) × hb宽
ty = hb.y0 + rand(0.30, 0.78) × hb高
命中 = b.x∈(hb.x0,hb.x1) && b.y∈(hb.y0,hb.y1)
```

命中只产生 `recoil .1s`、`hitFlash .18s`（约 0.18 秒红闪）、`shake`，
**不掉血、不死亡、不中断**。

## 五、经济与成长

### 5.1 核能

```
passive()     = (2.5 + 1.4×代谢等级) × M × (辐射汲取 ? 1.25) × (1 + energyBoost)
rewardMult()  = (1 + (代谢等级−1)×0.12) × (辐射汲取 ? 1.25)
M = 1 + (L−1) × 0.07        ← 只放大挂机收益，不放大攻击力
```

所有击杀/拆楼/推进的核能都过 `grant()`，内部乘 `rewardMult()`。

破坏收益具体值：拆楼 `30 + 楼高×0.11`，击破单位 = 上表 `reward`，推进 `180 + d×30`。

### 5.2 经验与升级

```
nextXP(L) = round(260 × L^1.28)

xpPerEnemy(d)    = round(12 × Ke(d))          Ke = 1+(d−1)×0.19
xpPerBuilding(d, layer) = round((layer===1 ? 24 : 12) × Kb(d))   Kb = 1+(d−1)×0.22

### 5.6 随机突变（骰子）

两段抽取，**全部确定性**（`hashSeed` + `mulberry32`，绝不 `Math.random`）：

```
① 稀有度权重抽一档：
   common 60 / fine 25 / rare 11 / epic 3.5 / legend 0.5
② 在该档里按类别抽：stat 55 / part 30 / element 12 / trait 3
```

- 骰面 = 稀有度单面：common → 1 或 2 面，fine → 3，rare → 4，epic → 5，legend → 6。
  `FACE_WEIGHTS` 记录灌铅概率（1 面 34%、6 面 0.5%），**骰子动画不参与计算**，
  它只是落在已经算好的那个面上。
- 同一级重掷要换结果：把**已抽次数**混进种子
  `seed = data.seed ^ imul(mutations.length+1, 2654435761)`。
- **先落盘再播动画**（`rollEvolution` 返回前已 `push` 进 `data.mutations`）。
- 重掷价格 `round(5000 × 1.6^已重掷次数)`。

突变池 4 类共 32 条，改的是这四样东西：

| 类别 | 落点 | 例子 |
| --- | --- | --- |
| stat 属性 | `morph.dmgBoost / beamBoost / energyBoost / speedBoost` | 力量增生 +4% |
| part 部位 | `morph.spikes / spikeScale / tailSegs / claws / horns / plates / twinTail / stompBoost / tailBoost / pressResist / hitFlash` | 脊刺增生（背刺 +2 根，重踏 +5%） |
| element 元素 | `subElements[]`、`aura`、`energyBoost` | 鳞片蓄热 → 获得 pyro 副特效 |
| trait 质变 | `morph.hue`、`colossal`、`extraScale`、`elemental`、`crit` | 赤化（体色转红，全伤 +12%） |

**背鳍类突变受 15 级门禁过滤**（`gateFor()`：`part === 'spikes'` → `GATES.spines`），
过滤后若整档被清空则退回未过滤池，保证任何等级都抽得出东西。

### 5.7 离线

```
seconds = min(8h, now − lastSeen)                      // < 10 秒不计
efficiency = (原始觉醒 ? 0.9 : 0.65) + 0.05 × 无眠等级   封顶 1
rate  = passive() + 7 × rewardMult()
核能  = seconds × rate × efficiency
经验  = round(核能 × 0.12)
```

折算比 0.12 是**实测标定**的：出厂默认在线挂机 8 小时的 XP/核能 ≈ 0.131，
取略低一档保证离线严格劣于在线。离线**不伪造击杀、不推进城区**，但发经验 ——
否则等级一停，dna / 加点 / 进化 / 天赋四条线一起饿死。

### 6.1 体型（`growth.js` 唯一真源）

```
base(L) = 本档 lo + (hi − lo) × (L − 本档min)/(下一档min − 本档min)     // 分段线性
growFactor = 1 + 0.02×巨躯 + 0.03×熔核 + 0.03×巨躯化 + extraScale
bodyScale = min(1.12, base × growFactor)                              // CEIL = 1.12
```

| 形态 | 等级 | 体型区间 | 锚点 |
| --- | --- | --- | --- |
| 幼兽 | 1 → 25 | 0.34 → 0.58 | L1 = 0.34、L15 = 0.48 |
| 亚成体 | 25 → 50 | 0.58 → 0.76 | L25 = 0.58 |
| 成体 | 50 → 75 | 0.76 → 0.90 | L50 = 0.76 |
| 完全体 | 75 → 100 | 0.90 → 1.00 | L100 = 1.00 |
| 灾厄体 | 100+ | 1.00（基础饱和） | 之后只靠天赋与突变 |

### 6.2 屏幕表观（真正的判据）

```
cameraScale(L) = min(1.30, 1.02 / bodyScale(L))
apparent(L)    = bodyScale(L) × cameraScale(L)      ★ 探针与测试都该量这个乘积
```

- 上限怎么来的：地面线 `720×0.72 = 518.4px`，顶部字幕条底边 ≈ 185px，
  满体型骨骼高 `401.2px` → `(518.4−185)/(401.2×0.8) ≈ 1.038`，取 **1.02** 留余量。
- `1.02` 是**防溢出保险丝**，不是"越高级越远"。它 **L53 起才生效**，之前镜头恒 1.30。
- 这一项**未计入背鳍**（`BIND_BOUNDS` 是身体轮廓，背鳍另画）。
- L50 之后表观趋近上限 —— 那是屏幕物理高度决定的，要更长得先给顶部 UI 让位。
- `STAGES[].camera` 已删除，`tests/growth-system.test.cjs` 断言它不许回来。

unlocked(feature, L) = 已登记 && L ≥ GATES[feature]      // 未登记一律 false，不静默放行
spineCount(L, bonus) = L < 15 ? 0 : 2 + floor((L−15)/12) + bonus
                        L15=2  L27=3  L39=4  L51=5 … L99=9
```

### 6.4 皮肤与背鳍装配

- 身体**全阶段无烘焙鳍**：`clean / jade / frost / ember / void` 五档无鳍贴图
  （幼兽 clean、亚成 clean、亚成体 jade、成体 frost、完全体 ember、灾厄 void）。
- 颜色突变**优先于形态底色**：赤化→ember、白化→frost、翠化→jade、玄化→clean。
- 背鳍由 `rig.js` 的 `FinRenderer` 独立装配，9 个固定挂点（`FIN_ANCHORS`），
  超出则第二排（坐标 +9/+12，`secondary` 再 ×0.72）：

```
鳍高 = 本档美术高 × min(1.55, (1 + 0.2×脊刺天赋) × 突变鳍长倍率) × bodyScale × 部位衰减
部位衰减：躯干 1，其余 0.62；分叉再让宽度 ×1.18
```

- 皮肤整套加载成功才换（`skinRequest` 序号拦截乱序完成），**不会先删身体等加载**。

BIND_BOUNDS  = bind pose（全关节角 0）下所有部件轴对齐矩形的并集

## 九、存档

### 9.1 两级封装

```jsonc
// <userData>/save/tv.json        ← 外壳写的
{
  "version": 1,
  "payload": "{\"version\":4,\"energy\":10038.1,…}"   // ← 画面自己的完整 JSON，原样字符串
}
```

`payload` 保持**字符串**而不是解析后的对象 —— 它就是 localStorage 里原本那个值，
往返不丢字段。画面那一侧的键是 `gnn-kaiju-idle-v3`，`tv-preload.js` 只劫持
**这一个键**，其余读写原样放行。

### 9.2 写盘时机

| 时机 | 方式 |
| --- | --- |
| 每 5 秒（`saveTimer ≥ 5`） | 异步，接管层再防抖 1 秒 |
| `pagehide` / `visibilitychange` | **同步** `sendSync`（等不到异步回调） |
| 加点 / 技能 / 偏好变更 / 推进 / 里程碑 | 立即 `save()` |
| 导入存档之后 | 整页重载，重握手 |

写入顺序固定：**临时文件 → fsync → 主档改名成备份 → 临时文件改名成主档**，
两次改名都是原子的。代价是备份永远落后一个周期（5 秒），换来永远读不到半个 JSON。
主档读不出自动回退备份；导出时按"读得出来"挑来源而不是"文件在不在"。

### 9.3 存档版本与兼容（最危险的地方）

`progression.js` 当前 `version: 4`，`sanitize()` **同时接受 3 和 4**：

- 只把版本号改成 4 就等于把所有旧档判废、回落成 1 级 —— 几个月进度一次性归零且不报错。
- 新字段（`talent / talents / assign / evoRolls / mutations / rerolls / morph /
  talentResets / subElements / seed / mapStart*`）就地补齐默认值。
- `seed` 派生**必须确定性**：`hashSeed(cleared×7919 + kills×104729 + round(meters), level)`，
  绝不用 `Date.now()` / `Math.random()`；派生一次后立即落盘，之后永远从存档读。
- 数值一律钳制：等级/区域 ≥ 1、`levels[k] ∈ [1,500]`、`plates ≤ 9`、`spikes ≤ 60`、
  `spikeScale ∈ [1,1.6]`、`talents[id] ∈ [0,3]`、`skills` 只保留登记过的 id。

### 9.4 world 快照

只存 `p.x − 2200` 范围内的建筑与固定敌人，避免存档随挂机时长无限膨胀：

```
district · stage · x · nextDistrict · mapStartCleared · mapStartKills · worldChunk
buildings: [{id, hp, max, dead}]
enemies:   [{id, hp, state}]        // 只存 fixed 的
```

动态增援不落盘；固定敌人击破后刷新**不会**再发奖励（靠 `state` 恢复）。

## 十、外壳与面板

| 层 | 关键做法 |
| --- | --- |
| 电视窗口 | `transparent:true` + `backgroundColor:'#00000000'`，页面侧再由 `TV_TRANSPARENT_CSS` 抹掉 `html,body` 底色 —— **两层都改才算数** |
| 启动遮罩 | `dom-ready` 先刷 `TV_STARTUP_CSS` 不透明底，`did-finish-load` 再被透明那条覆盖；两条选择器与 `!important` 相同，靠**后插入者胜**，所以**注入顺序不能调换** |
| 缩放 | 布局视口恒 `1120×736`，`系数 = 窗口宽/1120`；保持桌面宽视口再整体缩小，才能逐像素对上原版（绕开 1050 / 680 两个窄屏断点） |
| 拖动 | 注入一条只含 `-webkit-app-region` 的规则，**不许夹带任何视觉属性** |
| 面板窗口 | 独立窗口、`zoom` 显式钉死 1（否则会静默继承电视的 0.41）、**故意不透明**、只注入 `PANEL_ONLY_CSS` + `PANEL_READABLE_CSS` |
| 面板存档 | **只读**：`setItem` 对存档键直接丢弃。两个实例都能写就是谁后写谁赢，磁盘上看不出异常 |
| 面板操作 | 走 `panel:tap` → 电视窗口 `panelCommand()` 执行。切 tab / 关窗**不转发**（`talentTab` 也带 `talent` 前缀，正则放行会让电视弹自己的面板盖住直播） |
| 电视窗口的 `#management` | `guardMainPanel()` 用 MutationObserver **永久按住 hidden**，所以 `hud()` 里 `if(!$('management').hidden)` 在电视侧恒假 —— 成长按钮的门必须由 `syncGrowthGates()` 挂在 `hud()` 心跳上 |
| 渲染进程死亡 | `render-process-gone` 会 `contents.reload()` 重建一次（`clean-exit` 跳过），避免白板永久化 |
