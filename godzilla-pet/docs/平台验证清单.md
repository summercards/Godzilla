## 一、在 Windows 上把项目跑起来

```bash
git clone https://github.com/summercards/Godzilla.git
cd Godzilla/godzilla-pet          # ⚠️ 工程在子目录，不在仓库根
npm install
npm start
```

预期：`npm install` 拉 Windows 版 Electron；`npm start` 弹出无边框小电视窗。

**先跑这三条，确认工具链本身跨平台**（这步测的不是游戏，是测试脚本）：

| 命令 | macOS 实测 | Windows 实测 |
|---|---|---|
| `npm test` | `1..75` / `# pass 75` / `# fail 0` | |
| `npm run assets:check` | `OK  rig.json / rig.data.js 与 parts.json、11+1 部件图四者一致（12 槽位，装配比例 0.4）`，EXIT=0 | |
| `node tv/tests/idle.cjs` | EXIT=0 | |

> **已排除的一个风险**：`npm test` 的 glob 写在引号里（`node --test "tests/*.test.cjs" "tv/tests/*.cjs"`），Windows 的 cmd/PowerShell **不展开 glob**，本来会挂。但 macOS 上 zsh 同样不展开引号内的 glob，却跑出了 75 项 —— 说明是 **Node 自己展开的**，与 shell 无关。所以 Windows 上预期一致。**仍需实测确认。**

## 二、macOS 对照基线（实测）

### 窗口与缩放（`tv-shot.cjs` 输出原文，node v22.22.2）

| 档位 | 窗口 | zoom | 视口 | 字号契约 |
|---|---|---|---|---|
| small | 448×294 | **0.4000** | 1120×735 | PASS |
| medium | 520×342 | **0.4643** | 1120×736 | PASS |
| large | 600×394 | **0.5357** | 1120×735 | PASS |

`zoom = 窗口宽 / 1120`（`tv-config.js:152`）。**三档全是非常整数倍** —— 这一点在下面第 6、7 项会变成关键。

### 拖拽区（`tv-shot` 的 `REGION` 行）

```
body=drag  shell=no-drag  header=drag  footer=drag  dock=no-drag
```

电视外壳 / 顶栏 / 底栏可拖，画面本体保持可交互。

### 静态分析已确定的两处（**不需要实测，属 Electron 的文档化行为**）

| 位置 | 代码 | Windows 上的结果 |
|---|---|---|
| `main.js:234` | `w.setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true })` | **该 API 在 Windows 上不做任何事**（Electron 只在 macOS/Linux 实现）。此处**无平台守卫**，会静默无效 |
| `main.js:233` | `w.setAlwaysOnTop(true, 'screen-saver')` | `level` 参数为 **macOS 专有**，Windows 会忽略 → 退化成普通置顶 |

`:232` 的注释写的是「screen-saver 层级高于普通置顶，能压在**菜单栏与全屏窗口**之上」—— 这是 macOS 语义，到 Windows 上不成立。

## 三、8 项观察清单（逐项）

### 1｜窗口能否出现

- **怎么测**：`npm start` 后看桌面。
- **macOS**：正常。无边框、深色（`backgroundColor:'#050a15'`）、无标题栏、无 Dock 图标。
- **Windows 预期**：应正常。`transparent:false` 已避开透明窗在 Windows 上的历史坑。

### 2｜`setAlwaysOnTop` 在 Windows 上到底置到哪一层

- **依据**：`main.js:233`。见上表 —— `level` 被忽略。
- **预期**：能压普通窗口，但**压不住全屏应用、也压不住任务栏**。
- **怎么测**：① 打开记事本/浏览器看谁在上；② 播一个全屏视频，看小电视是否还在最上；③ 点任务栏，看是否盖住小电视。
- **记录**：

### 3｜拖动是否可用

- **依据**：`TV_DRAG_CSS`，`tv-config.js:48-55`。
- **macOS**：`REGION` 显示注入生效，实际拖动跟手。
- **预期**：`-webkit-app-region: drag` 在 Windows 同样支持；但**双击拖拽区**的行为两边不同（macOS 是缩放窗口，Windows 通常是最大化/还原 —— 而这两个窗口都是 `resizable:false` + `maximizable:false`，值得看有没有异常）。
- **怎么测**：抓电视外壳拖；再双击外壳一次。
- **记录**：

### 4｜托盘图标是否出现、是否被折进溢出区

- **依据**：`main.js:373` —— Windows 走 `tray.png`。
- **已知差异（资源层）**：

  | 平台 | 用的文件 | 格式 |
  |---|---|---|
  | macOS | `trayTemplate.png` | 16×16，**8-bit 灰度模板图**，自动适配菜单栏明暗 |
  | Windows | `tray.png` | **32×32，彩色 RGBA** |

  Windows 托盘标准尺寸是 16×16 → Electron 会缩小它，**可能发虚**；且彩色图不会像 macOS 模板图那样自适应任务栏明暗。
- **预期**：图标会出现，但**大概率落在溢出区**（要点 `^` 才看得到）—— 这直接影响 Step 5（退出入口）。
- **怎么测**：看右下角托盘区；点 `^` 展开溢出区找；**在深色任务栏下确认是否看得清**。
- **记录**：

### 5｜面板能否打开、`panelBounds` 定位是否合理

- **依据**：`main.js:280` `screen.getDisplayMatching(b).workArea` + `tv-config.js:135` `panelBounds`。
- **macOS**：面板出现在电视右侧、10px 间隙；贴屏边时自动翻到左侧或下方。
- **预期**：Windows 的 `workArea` **会扣掉任务栏**，而任务栏可在上/下/左/右四边 → `panelBounds` 里那四个 clamp 分支都要验。
- **怎么测**：① 把电视拖到屏幕**右下角**再开面板（最易触发翻转分支）；② **把任务栏移到屏幕左侧**再试一次。
- **记录**：

### 6｜跨 DPI 拖动后电视是否变小/变糊 ← **最关键的一项**

- **依据**：`tv-config.js:152` `zoomFor(w) = w / 1120`，**只认窗口宽度**。
- **机理**：Windows 上 `getBounds()` 返回 DIP。窗口从 100% DPI 屏拖到 150% DPI 屏时：
  - 若系统保持 DIP 不变 → `w` 不变、`zoom` 仍 0.4000，但物理像素数放大 1.5 倍 → **像素画糊**
  - 若系统保持物理尺寸 → `w` 变小、`zoom` 跟着变小 → **电视突然缩水**
  
  两条路都出问题。而三档 zoom 全是非常整数倍，非整数倍缩放本身就是像素字体的大敌。
- **怎么测**：两台不同缩放的显示器（或 100% / 150% 系统缩放对照）。把电视拖过去，看 ① 是否变小 ② 是否变糊 ③ 重启后是否保持。
- **记录**：
- ⚠️ **若确认失真 → 按技术线文档的升级条件，本项插入成为独立步骤，其余步骤顺延。**

### 7｜像素字体渲染 + 字号契约是否还成立

- **依据**：阈值是 **macOS 下量的**（`build/tv-shot.cjs`）。
- **macOS**：三档全 `PASS 所有可见文字字号不小于左侧按钮`。
- **预期**：Windows 字体栈不同（DirectWrite vs CoreText），`tv/assets/fonts/` 的像素字体可能笔画发灰/糊；非整数倍 zoom 会加剧。
- **怎么测**：三档各截一张图，与 macOS 截图肉眼对比（重点看页脚、台标这些最小字号）。
- **记录**：

### 8｜存档能否写入中文路径

- **依据**：`app.setName('巨兽都市桌宠')` → 存档落在 `%APPDATA%\巨兽都市桌宠\save\tv.json`。
- **macOS**：`~/Library/Application Support/巨兽都市桌宠/save/tv.json`，正常。
- **预期**：NTFS 用 UTF-16，中文目录名通常没问题；但要实测 `%APPDATA%` 拼接 + Node 编码，以及**中文路径遇到杀软/云同步盘**的情况。
- **怎么测**：启动后找到存档文件，确认存在、内容合法；改一点进度，确认落盘。
- **记录**：
